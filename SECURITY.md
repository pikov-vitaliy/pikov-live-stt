# Pikov LiveSTT Security Policy

> Modified in 2026 by Vitaly Pikov for Pikov LiveSTT; based on the upstream
> WhisperLiveKit security policy.

## Supported versions

Before the first Pikov LiveSTT release, only the current `main` branch is
supported. After releases begin, this section will list their support status.

The upstream WhisperLiveKit engine follows its own support policy. Reports that
affect unchanged upstream code may be coordinated privately with the upstream
maintainer after validation.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use this repository's
[private vulnerability reporting form](https://github.com/pikov-vitaliy/pikov-live-stt/security/advisories/new)
instead.

Include the affected commit, impact, reproduction steps, relevant configuration,
and any suggested mitigation. Use synthetic or public-domain audio when an audio
fixture is essential. Do not attach real meeting recordings, transcripts,
credentials, personal data, or unrelated private material.

Please allow time to validate the report and prepare a coordinated fix before publishing details.
