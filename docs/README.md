# Документация локального контура

Локальная транскрипция браузерных видеоконференций и роликов: звук вкладки и микрофон уходят в WhisperLiveKit на этой же машине, результат читается в боковой панели браузера и пишется в Markdown.

| Документ | Когда открывать |
|---|---|
| [Операционная инструкция](LOCAL-CONFERENCE-TRANSCRIPTION-RU.md) | Первый запуск, запуск после перезагрузки Windows, повседневная работа, проверка сервиса, экспорт |
| [Состояние и принятые решения](LOCAL-CONFERENCE-STATE-RU.md) | Что работает сейчас, почему сделано именно так, что осталось открытым |
| [Полный перечень изменений](LOCAL-CONFERENCE-TRANSCRIPTION-CHANGES-RU.md) | Чем текущий контур отличается от исходного `v0.2.25` |
| [Инструкция к расширению](../chrome-extension/README.md) | Установка расширения, кнопки панели, микрофон, экспорт |

Если распознавание молчит, а сервис выглядит здоровым — начните с
`pwsh -File scripts\check-conference-service.ps1`: `/health` в этом контуре
не является доказательством работоспособности.
