# WhisperLiveKit: устойчивая транскрипция аудио вкладки Chrome

Расширение захватывает звук выбранной вкладки и передаёт его в локальный WhisperLiveKit по WebSocket. По желанию к нему подмешивается ваш микрофон — по умолчанию он выключен и запрашивается отдельно.

```text
Клик по иконке на вкладке встречи
  -> фоновый offscreen-документ захватывает звук вкладки
  -> ws://127.0.0.1:8001/asr
  -> локальный WhisperLiveKit
  -> боковая панель Chrome с живой транскрипцией
```

В отличие от прежней реализации в popup, захват, WebSocket и `MediaRecorder` живут вне интерфейса. Поэтому клик вне панели или её закрытие не останавливают транскрипцию.

## Требования

- Chrome 116 или новее (для service worker → `tabCapture.getMediaStreamId()` → offscreen document);
- локальный сервер WhisperLiveKit, доступный по `ws://127.0.0.1:8001/asr`;
- вкладка с конференцией, открытая в Chrome.

## Установка и запуск

1. Запустите локальный сервер из корня репозитория:

   ```powershell
   docker compose -f compose.conference.local.yml up -d
   Invoke-RestMethod http://127.0.0.1:8001/health
   ```

2. Откройте `chrome://extensions` (в Brave — `brave://extensions`), включите «Режим разработчика» и загрузите распакованное расширение из `V:\WhisperLiveKit\chrome-extension`.

3. Если расширение уже было загружено, нажмите его кнопку «Обновить» на странице `chrome://extensions`. Это обязательно после перехода с popup на боковую панель.

4. Откройте вкладку Контур.Толка, убедитесь, что звук вкладки слышен, и нажмите иконку `WhisperLiveKit Tab Capture` в панели Chrome.

5. Chrome откроет боковую панель и транскрипция начнётся автоматически. В панели оставьте адрес `ws://127.0.0.1:8001/asr`.

6. Работайте со встречей как обычно: можно кликать по вкладке, переключаться внутри интерфейса Толка, закрывать и снова открывать боковую панель. Повторный клик по иконке в той же вкладке только откроет панель и не перезапустит захват. Для паузы и остановки используйте кнопки панели — см. раздел «Управление записью».

Закрытие самой вкладки встречи также завершает захват и освобождает фоновую сессию.

## Управление записью

| Кнопка | Что делает |
|---|---|
| **⏸ Пауза** | Останавливает запись, **не разрывая сессию**: вкладка остаётся захваченной, соединение живым, файл сохраняет всё уже записанное. Микрофон при этом отключается. |
| **▶ Продолжить** | Возобновляет запись и открывает в файле новый фрагмент, названный по заголовку вкладки **в этот момент**. |
| **⏹ Завершить** | Полный останов: отпускает вкладку, закрывает сессию, отвязывает файл. |
| **🧹 Очистить экран** | Убирает текст с экрана насовсем. Архив, файл и автосохранение не трогаются — запись продолжается. |

Пауза рассчитана на сценарий «смотрю подряд, записываю выборочно»: один файл на весь сеанс, внутри — только те фрагменты, которые вы отметили.

Про очистку экрана стоит знать одну деталь. Сервер держит реплику открытой, пока не услышит паузу дольше пяти секунд, и всё сказанное дальше дописывает **в ту же реплику**. Поэтому очистка запоминает, какая часть текста уже была показана, и дальше выводит только то, что добавилось. Убранное не возвращается, а речь, которая продолжается в той же реплике, на экран попадает.

Технически на паузе останавливается сам `MediaRecorder`, а не отбрасываются куски данных. Это принципиально: если просто перестать отправлять, в потоке WebM образуется дыра и сервер не сможет декодировать дальше. Безопасность паузы проверена живым тестом — 30-секундный разрыв сервер переносит, речь после него распознаётся.

Каждое «Продолжить» даёт в экспорте отдельный заголовок:

```markdown
### 20:10 — Разбор инцидента с утечкой
...

### 20:41 — Настройка SIEM: практика
...
```

Если пауз не было, заголовки не добавляются.

## Микрофон

Захват вкладки записывает только то, что вкладка **воспроизводит**, — то есть собеседников. Ваш собственный голос идёт во вкладку, а не из неё, и без микрофона в стенограмму не попадает.

Галочка **«Записывать мой микрофон»** в панели включает его. При первом включении откроется вкладка с разовым запросом доступа: браузер не показывает такой запрос из фонового документа, поэтому он вынесен на отдельную страницу. Разрешение выдаётся один раз для расширения.

- Микрофон подмешивается **только в запись**. В динамики по-прежнему идёт один звук вкладки — себя вы не услышите.
- Включены эхоподавление, шумоподавление и автоусиление. При прослушивании из динамиков это не даёт репликам собеседников попасть в текст дважды.
- Расширение берёт **свой** поток с микрофона. То, что видеоконференция уже им пользуется, этому не мешает — устройство разделяется.
- Выбор применяется **со следующего запуска захвата**: поменять источник звука посреди записи нельзя.
- Если доступ не дали или устройства нет — запись не срывается, идёт без микрофона, и панель об этом сообщает.

> **Важно понимать.** Разрешение выдаётся расширению, а не конференции. Если вы отключите микрофон **в самой конференции**, расширение продолжит вас записывать — это разные вещи. Чтобы гарантированно ничего не писалось, нажмите **⏸ Пауза** (микрофон отключается) или **⏹ Завершить**.

## Работа с текстом в панели

Стенограмма перерисовывается точечно, поэтому текст можно выделять мышью прямо во время речи и прокручивать назад, не будучи возвращённым вниз.

- **Наведите на реплику** — справа появится кнопка «Копировать»; она копирует только эту фразу.
- **Двойной клик по реплике** — то же самое, без наведения.
- **Ctrl+клик** — добавляет реплику к выделению; обычный клик не занят, чтобы не мешать выделению текста мышью. Внизу появится «Копировать выбранное».
- Прокрутка вверх отключает автопрокрутку; вернуться к живому тексту можно кнопкой «↓ Новые реплики».
- `A−` и `A+` меняют только размер текста стенограммы; значение сохраняется в профиле браузера.

## Экспорт стенограммы

Формат выбирается в списке «Формат»:

| Формат | Что даёт |
|---|---|
| **Диалог** (по умолчанию) | Сплошной текст абзацами, таймкод при смене говорящего или после паузы. Если говорящий один, метки «Спикер 1» не ставятся. |
| **С таймкодами** | По одной строке на реплику с интервалом времени. |
| **Простой текст** | Без Markdown-разметки и экранирования. |

- «Копировать всё» кладёт стенограмму в буфер обмена в выбранном формате.
- «Сохранить .md» скачивает файл с именем вида `2026-08-16 14-05 Контур.Толк.md` — локальные дата и время плюс заголовок вкладки встречи.
- Экспорт содержит все реплики сессии, а не только видимые в панели.

## Живая запись в файл

Кнопка «Писать в файл…» позволяет выбрать `.md` в любой папке — например, рядом с материалами конкретной встречи. Дальше расширение переписывает этот файл по ходу разговора, так что его можно держать открытым в VS Code и наблюдать, как появляется текст.

- Папку можно выбирать заново для каждой встречи; браузер запоминает последнюю.
- Во время записи рядом с файлом ненадолго появляется служебный `.crswap` — так Chrome обеспечивает атомарную замену содержимого.
- Файл переписывается целиком, а не дополняется: политика распознавания правит уже выданный текст, и дописывание оставляло бы устаревшие фразы.
- Если браузер не разрешит запись из фонового документа, файл будет обновляться только пока открыта панель — статус под кнопкой прямо об этом скажет.

## Автосохранение и восстановление

Стенограмма пишется в `chrome.storage.local` раз в 15 секунд. Это переживает перезапуск Chrome и перезагрузку Windows, поэтому обрыв встречи больше не означает её потерю: при следующем открытии панель предложит «Восстановить» или «Удалить».

Сохранённые стенограммы удаляются автоматически через 7 дней, хранится не больше 10 последних. Долговременный результат по-прежнему создаётся только явным «Сохранить .md» или живой записью в файл.

Полная инструкция по перезапуску Docker Desktop и повседневной работе находится в [документации проекта](../docs/LOCAL-CONFERENCE-TRANSCRIPTION-RU.md).

## Защита данных

- Адрес сервера ограничен `ws://` на loopback (`127.0.0.1`, `localhost` или `::1`) и путём `/asr`; расширение не примет внешний WebSocket-адрес.
- Аудиопоток не записывается расширением на диск.
- Текст встреч хранится в профиле браузера до 7 дней ради восстановления после сбоя. Кнопка «Удалить» в блоке восстановления стирает конкретную запись. Данные не синхронизируются в Chrome Sync.
- Во время активного захвата на иконке расширения горит значок `REC` — видно с любой вкладки.
- Не публикуйте порт Docker в локальную сеть. Для данного PoC он должен оставаться `127.0.0.1:8001`.
- До реальных встреч уведомляйте участников о транскрибировании и соблюдайте внутреннюю политику обработки данных.
